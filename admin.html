Danh sách điều khoản Admin đã thêm

Đồng bộ Cloud & Cài đặt Ứng dụng

Kết nối Firebase Realtime Database miễn phí để chỉnh trên điện thoại là mọi máy đều tự cập nhật.

1. Đồng bộ đa thiết bị (Firebase Realtime Database)

Chưa gắn Cloud
Hướng dẫn lấy link Firebase miễn phí trong 2 phút:
1. Vào console.firebase.google.com → Tạo dự án mới (Miễn phí).
2. Chọn Build → Realtime Database → Create Database (chọn khu vực Singapore, chế độ Test mode).
3. Copy đường dẫn URL màu xanh phía trên bảng dữ liệu rồi dán vào ô trên và bấm Lưu & Đồng bộ.

2. Đổi mật khẩu Đăng nhập Admin

3. Cài ứng dụng Admin này lên Màn hình chính điện thoại

• Trên iPhone (Safari): Bấm biểu tượng Chia sẻ (ô vuông mũi tên lên) ở thanh dưới → cuộn xuống chọn "Thêm vào MH chính" (Add to Home Screen) → bấm Thêm.
• Trên Android (Chrome): Bấm nút "Cài App" màu đỏ góc trên cùng hoặc bấm dấu ⋮ → chọn "Cài đặt ứng dụng".
Cài DTU Admin lên Điện thoại
Cho iPhone (Trình duyệt Safari):
1. Mở trang này bằng Safari.
2. Bấm nút Chia sẻ (ô vuông có mũi tên chỉ lên ở cạnh dưới).
3. Chọn "Thêm vào MH chính" → bấm Thêm.
Cho Android (Trình duyệt Chrome):
Bấm dấu ⋮ ở góc phải trên → chọn "Cài đặt ứng dụng" hoặc "Thêm vào màn hình chính".
